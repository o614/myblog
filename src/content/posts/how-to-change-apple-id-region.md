## 先说结论

改区前要先清空账户余额，结束会阻止改区的订阅，退出家庭共享，并等待预购、租借和退款处理完成。改区时可能需要目标地区的有效付款方式和真实账单地址。

这些条件会变化，请先核对 [Apple 官方改区说明](https://support.apple.com/118283)。

## 改区前检查

- Apple 账户没有余额或欠款
- 相关订阅已经取消，并已过有效期
- 已退出家庭共享
- 预购、租借、会员项目和退款已经处理完成
- 已备份或重新下载以后仍要使用的内容
- 准备好目标地区支持的付款方式和真实账单资料

部分内容在新地区可能无法继续获取。只是偶尔下载外区 App 时，单独注册一个外区账号通常比频繁修改主账号地区更稳妥。

## 在 iPhone 或 iPad 上改区

1. 打开“设置”，点击自己的名字。
2. 进入“媒体与购买项目”→“查看账户”。
3. 点击“国家/地区”→“更改国家或地区”。
4. 选择目标地区，阅读并同意条款。
5. 按页面要求填写付款方式和账单地址。
6. 保存后重新打开 App Store，确认商店地区。

也可以登录 [Apple 账户官网](https://account.apple.com/)，在“个人信息”里的“国家或地区”按提示操作。

## 为什么改不了

| 原因               | 怎么处理                                     |
| ------------------ | -------------------------------------------- |
| 账户仍有余额       | 用完余额；金额低于最低消费时联系 Apple 支持  |
| 订阅仍在生效       | 取消后等待当前周期结束                       |
| 仍在家庭共享中     | 先退出家庭共享再尝试                         |
| 有待处理订单或退款 | 等项目完成后再改区                           |
| 付款或账单资料无效 | 使用目标地区支持、且与本人付款资料一致的信息 |

不要照抄陌生地址，也不要短时间连续改区。虚假或不匹配的信息可能导致付款失败或触发账户验证。

如果只看到“出现错误，请稍后再试”，先停止反复提交，换到 [account.apple.com](https://account.apple.com/) 核对账户状态，并逐项排除余额、订阅、家庭共享、待处理订单和付款资料。网上流传的“先登录 iCloud 网页就能解锁改区”没有 Apple 官方说明，不应当作必然有效的步骤；条件都满足后仍失败，直接联系 [Apple 支持](https://support.apple.com/zh-cn) 更稳妥。

## 改区后的影响

- 部分 App、影视、音乐或图书在新地区可能不可用。
- 原来安装的 App 通常还能使用，但更新时可能需要原购买账号。
- iCloud+ 价格和可用服务可能按新地区调整。
- 账户有余额时通常不能再次改区。
